อัปเดตรอบล่าสุดรวมรายการที่จดไว้:
- ป๊อปอัปผู้ควบคุมไม่มีเส้นคั่นระหว่างช่อง ปุ่มเพิ่มใช้ธีมเดียวกับบันทึก
- สถานะอนุมัติสารเคมีและ SDS เพิ่ม “ไม่เกี่ยวข้องกับสารเคมี”
- ระดับผลกระทบคงเดิมทุกตัวเลือก
- บริษัทส่งงานงวดที่เริ่ม 1 และใช้จำนวนรายการเดิมที่ตรงห้าเงื่อนไข + 1 เช่นเดียวกับจำนวนครั้งเข้าดำเนินการ
  แก้เลขเองได้ และผลค้นหาที่กลับมาภายหลังจะไม่ทับเลขที่แก้เองในกลุ่มเดิม
  หากเคยแก้งวดเป็น 7 ครั้งถัดไปยังนับจากจำนวนรายการ ไม่ใช่ต่อจาก 7 เพราะใช้หลักเดียวกับเข้าดำเนินการครั้งที่
- วันที่บริษัทส่งงานใช้ป๊อปอัปปฏิทินเดียวกับวันที่อื่น แสดงภาษาไทย ส่ง ISO
- บันทึกวันที่ส่งงานและงวดส่งงานในคอลัมน์เสริมตามชื่อ ไม่ทับข้อมูลเดิม

รอบนี้ต้องแทน index.html, script.js และ Code.gs แล้ว Deploy เวอร์ชันใหม่ที่ URL เดิม
เก็บ CONFIG เดิม ส่วน style.css ใน ZIP ใช้ชุดล่าสุดเดิม

อัปเดตหน้าตาผู้ควบคุมงาน: เอาเส้นกั้นระหว่างช่องออก และปุ่มเพิ่มใช้ธีม primary-btn เดียวกับปุ่มบันทึก
หากติดตั้งชุดก่อนแล้ว เปลี่ยนเฉพาะ script.js แล้ว Ctrl+F5 ไม่ต้อง deploy Code.gs

ชุดล่าสุด: รายชื่อฝังในโค้ดและปฏิทินวันลงนาม

รายชื่อ:
ฝังชื่อ-นามสกุลและตำแหน่ง 169 คู่จากไฟล์ข้อความที่ผู้ใช้ส่งวันที่ 9 พ.ย. 2569
ไม่ฝังคำนำหน้าหรือข้อมูลอื่น ไม่มีการสร้างรายชื่อหรือตำแหน่งขึ้นเอง
ทั้งประธาน หัวหน้า และผู้ควบคุมหลายคนพิมพ์อักษรต้นชื่อแล้วมีรายการแนะนำทันที
การค้นรายชื่อไม่เรียก Apps Script และไม่มีการหน่วงรอเครือข่าย
เลือกรายการแล้วแสดง ชื่อ นามสกุล (ตำแหน่ง) ในช่องเดียว แต่ส่งชื่อกับตำแหน่งแยกกัน
รายการหลายชื่อจำกัดครั้งละ 20 เพื่ออ่านง่าย พิมพ์เพิ่มเพื่อลดรายการ
รายการที่ไม่พบจะไม่เดาชื่อหรือตำแหน่ง

ข้อควรทราบ:
รายชื่อและตำแหน่งที่อยู่ใน JavaScript อ่านได้โดยผู้เข้าถึงเว็บ
นี่เป็นสำเนาข้อมูล ณ วันที่ได้รับไฟล์ ไม่ซิงก์กับชีต ต้องอัปเดตไฟล์เมื่อข้อมูลเปลี่ยน

ติดตั้ง:
ถ้าติดตั้งชุดล่าสุดที่มีปฏิทินวันลงนามและ backend ใหม่แล้ว ให้แทน script.js แล้ว Ctrl+F5
หากยังไม่เคยติดตั้งชุดใหม่ ให้แทน index.html, script.js, style.css และ Code.gs
เก็บ CONFIG เดิม แล้ว Deploy > Manage deployments > New version > Deploy ที่ URL เดิม
บันทึก Code.gs เฉย ๆ ไม่เปลี่ยนโค้ดที่ URL /exec ให้บริการ

วันที่ลงนาม:
ใช้ป๊อปอัปเดียวกับวันเริ่ม/สิ้นสุด แสดงภาษาไทยและเก็บ ISO
ดึงวันเดิมเฉพาะกลุ่มปี/สถานที่/หมวดงาน/PWI/เรื่องเดียวกัน
ถ้าแถวล่าสุดว่างจะค้นวันเดิมที่เคยเก็บในกลุ่มเดียวกัน ไม่ข้ามปีหรือเดาจากวันเริ่มสัญญา
URL ใน config ที่เคยตรวจยังตอบ backend เก่า จึงต้อง deploy ใหม่ให้ตรง URL ที่เว็บใช้งาน
วันที่ที่โค้ดเก่าไม่เคยบันทึกไม่สามารถสร้างคืนได้ ต้องตรวจเซลล์จริง

การรักษาฟอร์ม:
ช่องเดิมทุกช่องคงอยู่ ซ่อนเพียงช่องตำแหน่งใหม่ตามคำขอให้รวมในช่องชื่อ
เงินมูลค่าสัญญาและเงินสะสมแสดง comma แต่ส่งค่าตัวเลขไม่มี comma
วันเข้าดำเนินการ/วันแล้วเสร็จ/เลขส่งงานบริษัทกรอกเอง
จำนวนคนดึงครั้งก่อนและแก้ได้ นับครั้งตามกลุ่มห้าเงื่อนไขเดิม
สารเคมีใช้รายการเดิม 18 รายการ สารเคมีระบุเองต้องตรวจ SDS
